# apprs — учебные проекты The Rolling Scopes School

Учебные проекты, выполненные в рамках курса RS School (JavaScript/Front-end).

## Portfolio

Лендинг-портфолио фотографа на чистом JavaScript (без фреймворков): адаптивная вёрстка (десктоп/планшет/мобильные), интерактивный слайдер, модальное окно цен, аккордеон FAQ с сохранением состояния в localStorage, бургер-меню.

**Стек:** Vanilla JavaScript, Vite, Sass (mixins/placeholders), HTML5, SVG, WebP.

- Демо: https://kat-in.github.io/apprs/Portfolio/
- Код: https://github.com/kat-in/apprs/tree/Portfolio

## Структура репозитория

- Ветка `Portfolio` — текущая версия проекта
- Ветка `gh-pages` — сборка для GitHub Pages
- Ветка `portfolio-part2` — промежуточная версия второй части задания
